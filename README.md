One sentence, at most 200 characters, about the best meal ever had — written by a program, not typed into a form. `main.ts` holds the sentence as a fixed string, checks it against the bounty gate (1–200 characters, not only whitespace, exactly one sentence on one line), writes it to `/output/entry.txt` with no trailing newline, then reads the file back and refuses to finish unless it is byte-identical to the sentence that passed validation.

The meal: pork-bone congee, pressed into the author's hands by their grandmother at two in the morning, eaten standing in her doorway with steam fogging their glasses — because they could not wait to sit down.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (it runs TypeScript directly, no install step, no dependencies). It writes `/output/entry.txt` and prints the sentence and its character count. Running it twice produces byte-identical output.
